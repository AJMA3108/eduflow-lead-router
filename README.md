# EduFlow — AI Lead Routing for Coaching Institutes

> Built by [The AI Edge](https://ajma3108.github.io/AI-Edge-Projects)

## What It Does

Most coaching institutes lose students because leads 
from Facebook Ads, Google Ads, and website forms go 
to different places — and someone has to manually 
download, sort, and forward them.

**EduFlow fixes this:**

- Student fills an inquiry form on the website
- Lead instantly appears in the live dashboard
- Right counselor gets notified via Email automatically  
- Branch manager can update routing rules in real time
- Zero manual work. Zero dropped leads.
